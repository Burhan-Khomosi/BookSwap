# BookSwap – Second-Hand Book Exchange

BookSwap is a simple website where students can buy, sell and exchange used textbooks on campus. Students can browse the available books, see each book's price and subject, and contact the seller. They can also list their own books for sale.

This project was created as a CWS Mini Project.

## Features

- Responsive layout that works on desktop, tablet and mobile screens
- Smooth-scrolling navigation bar with Home, Browse, Sell and Contact sections
- A "How it works" section that explains the process in three steps
- Browse section with eight book cards designed in Figma
- Hover animations on the cards and buttons
- "Sell a book" form for listing a book
- "Contact us" form for sending a message

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3
- Google Fonts (Bitter and Nunito Sans)
- Figma (card and graphic design)


## How to Run Locally

1. Download or clone this repository.
2. Make sure the `images` folder is in the same folder as `index.html`.
3. Open `index.html` in any web browser.

An internet connection is required so that Bootstrap and Google Fonts can load.
